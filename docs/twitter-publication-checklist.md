# Twitter publication completion

Twitter is Anni's primary public sharing workflow. A successful HTTP fetch or deployed Open Graph tag does not complete publication handoff.

1. Finish and obtain approval for the actual share artwork before offering the public URL for a first share. Do not substitute a source photograph for a designed card without checking the intended treatment.
2. Deploy the final artwork under a new versioned asset filename and update Twitter/Open Graph tags together. Verify the deployed HTML and asset bytes.
3. Open an unsent Twitter composer and visually inspect the actual preview. Preserve existing draft text. Never report the Twitter card fixed based only on the website.
4. If Twitter still uses older artwork, test a stable versioned query URL for this release. Keep the canonical article URL unchanged. Do not hand off that URL until the new artwork visibly appears in Twitter.
5. If the link preview cannot be made to refresh, distinguish the remaining link-card failure from an attached-image fallback. A photo attachment is not a repaired clickable link card. Prepare a fallback only with clear labeling; never post without authorization.
6. Record the exact URL and the observed preview, then hand off the unsent draft. Retain that tested URL for the user rather than asking them to experiment with browser resets.
