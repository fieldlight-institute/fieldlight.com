System 01Distributed runtime

Fieldlight Mesh

A local-first relay and storage system for communication that remains useful when the cloud is absent, inappropriate, or untrusted.

Fieldlight Mesh tests peer discovery, scoped exchange, routing, fallback behavior, trust boundaries, and durable audit across small devices and local networks.

  • Local-first operation
  • Peer-to-peer relay
  • Bounded exchange
  • Durable event history

System 02Memory and continuity

Sanctum Zero

A local-first substrate for memory, authorship continuity, and explicit permission boundaries.

Sanctum Zero treats memory as governed infrastructure rather than ambient product exhaust. Its purpose is to preserve custody, legibility, and a human-owned source of truth.

  • Local custody
  • Authorship continuity
  • Explicit permission
  • Inspectable state

System 03Provenance and public record

Fieldlight Proofs

A public authorship record built from manifests, content hashes, and independently verifiable attestations.

Fieldlight Proofs preserves what was published, when it entered the public record, and whether the underlying material has changed.

  • Content manifests
  • SHA-256 hashes
  • OpenTimestamps receipts
  • Bitcoin attestations
